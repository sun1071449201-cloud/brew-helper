# 第三章 风味与质量异常：喝出来的线索

前两章讲的是"看得见"的异常。这一章讲"喝得出来"的——风味异常是酿造质量的最终裁决，而读懂它需要词汇和思路。这一章给你四类高频风味问题的排查地图。

## 3.1 氧化老化：纸板味、米酒味

### 3.1.1 为什么会出现

氧是啤酒保质期的头号敌人，但**氧的入口从来不止一个**：

1. 过滤顶机排气不彻底，机内空气直接顶进酒里
2. 灌装背压用了压缩空气（这根红线一碰就是整批）
3. 管路接头、泵密封微漏，负吸时进气
4. 脱氧水水质退化——顶机用水本身含氧，等于给酒"氧疗"
5. 清酒罐未 CO2 置换或置换不充分

### 3.1.2 排查步骤

1. 查这批酒的 DO（溶解氧）记录，从清酒到灌装全链路
2. 查过滤顶机排气操作记录与脱氧水检测数据
3. 查背压气源（是不是 CO2，别信口头说的，看管路标识）
4. 管路保压测试：负压段保不住压的就是漏点
5. 对比同期其他批次 DO，分清是系统问题还是操作问题

### 3.1.3 对策

逐个堵入口：排气步骤标准化、背压气源红线管理、漏点检修、脱氧水定期送检。**DO 是越早控越便宜的事——进瓶之后就没有回头路了。**

## 3.2 异臭：自溶味与硫化物

### 3.2.1 自溶（苦涩、酱油汤味）

酵母死亡破裂释放内含物。高发场景：

1. 储酒温度偏高、储存时间过长
2. 锥底酵母泥堆积太久没排
3. 酸度或酒精胁迫过强

排查：查储酒温度曲线与时间、查酵母排放记录。对策：控储存温度、按周期排酵母、老化风险批次提前过滤。

### 3.2.2 硫味（臭鸡蛋、洋葱味）

1. 酵母株性 + 发酵应力（温度过低、营养不足）
2. 染菌（硫化氢类异味常伴随菌群失控）

排查：镜检 + 微生物检测先行，分清酵母本性与染菌。对策：按菌株特性调温、确认麦汁营养；染菌走染菌流程。

## 3.3 浊度与冷浑浊：先分清类型

### 3.3.1 判断树

```
酒浑 → 回温试验
  ├─ 回温暖清 → 冷浑浊（蛋白-多酚可逆析出）：查过滤酒温波动、麦芽蛋白溶解度
  ├─ 回温仍浑、偏黄绿 → 酵母穿透：查滤层、预涂、压差
  └─ 摇后雾状持久、放置加深 → 胶体问题：送检 β-葡聚糖、查辅料与麦芽批次
```

### 3.3.2 对策

类型不同药方完全不同：冷浑浊看稳定性工艺，酵母穿透修过滤，胶体问题反馈原料。**拿着"浑"字去调参数，是这一章最容易犯的错。**

## 3.4 保质期内变酸：染菌的迟到账单

### 3.4.1 为什么出厂好好的，市场里酸了

产酸菌（乳杆菌、片球菌等）在出厂检验时可能数量低于检出限，但在瓶里慢慢长。**污染源头通常是灌装后半段的卫生死角**：

1. 灌装机 CIP 覆盖不到的死角（酒头、回气管）
2. 杀菌机 PU 不足（偶发欠杀批次）
3. 瓶盖/瓶口密封缺陷，微生物从外部进入

### 3.4.2 排查步骤

1. 收集投诉批次信息：生产日期、产线、班次——先圈范围
2. 留样复检：同批次留样做微生物富集培养
3. 查该班次灌装机 CIP/SIP 记录与擦拭试验数据
4. 查杀菌机 PU 曲线（重点看卡瓶、停链时段）
5. 瓶盖密封性抽检（扭矩、密封垫）

### 3.4.3 对策

死角改造（拆洗验证）、欠杀批次回溯隔离、密封件更换周期化。**市场投诉是微生物检测的"延时报告"——每一条都要倒查到工序并闭环。**

## 3.5 本章小结

风味异常排查的心法：**先定性（哪种味），再定源（哪个工序），最后定责（哪批哪班）**。App 的"酿造术语"库可以帮你建立风味词汇——描述得越准确，排查越快。

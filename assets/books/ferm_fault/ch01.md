# 第一章 发酵异常：温度、降糖与风味

发酵异常是车间里最常见的"疑难杂症"，因为它牵扯活的东西——酵母。这一章按四个高频症状来讲：温度高、降糖停滞、双乙酰反弹、DMS 偏高。

## 1.1 发酵罐温度高（控温压不住）

### 1.1.1 为什么会出现

发酵是放热反应，酵母越猛放热越多。温度压不住，无非三类原因：

1. **冷媒侧**：冷媒温度不够、阀门卡死、盘管结垢
2. **控制侧**：温度计漂移、控制器参数被人动过
3. **工艺侧**：接种量偏大或控温点偏低，发热量超过设计冷量

### 1.1.2 排查步骤

1. 现场温度计和 DCS 对表，差超过 2°C 先怀疑仪表
2. 摸冷媒管路进回温差，判断冷媒是否真在流动
3. 查冷媒设定温度与制冷机组负载（其他罐在不在抢冷）
4. 看近三天温度曲线：一直爬是冷量不足，刚爬多半是操作变了
5. 都正常，测冷媒流量、查盘管结垢，报设备

### 1.1.3 对策

对症处理：冷媒不足提负荷或错峰降温；阀门卡死切换手动报修；仪表漂移换表送校。工艺侧超发按规程手动补冷并记录偏差。

**千万别用大幅拉低控温点硬压**——骤冷酵母休眠，降糖停滞和双乙酰反弹会一起找上门。

预防靠两件事：大修校表清盘管；换季先核冷媒能力再排产。

## 1.2 降糖停滞

### 1.2.1 为什么会出现

按概率从高到低：

1. 温度被压得太低，酵母提前休眠（最常见）
2. 前期充氧不足或酵母活率低，发酵根本没铺开
3. 可发酵糖耗尽——**这不是故障，先核对目标发酵度**
4. pH 异常或染菌抑制
5. 酵母絮凝过早，醅里活性酵母不够

### 1.2.2 排查步骤

1. 核对工艺卡：是不是本来就到终点了
2. 测罐内上中下三点实际温度，排除局部过冷
3. 取样镜检：酵母浓度、形态、杂菌
4. 查充氧记录和接种报告
5. 复温试验：取样在正常温度下摇瓶，看是否恢复降糖

### 1.2.3 对策

温度问题按规程缓慢复温（每次 1°C 量级，观察 24 小时）。酵母问题报工艺员评估补种或回温。染菌按染菌流程处理。

预防：接种前把**活率、溶氧、温度**三件事查到位，比事后补救便宜十倍。

## 1.3 双乙酰反弹

### 1.3.1 为什么会出现

反弹 = 前体没还原干净，出罐后继续转化。常见源头：

1. 降温太早，前体没吃干净酵母就休眠
2. 酵母排放过早，还原期没剩多少活性酵母
3. 过滤时剪切搅动把沉底酵母带起来
4. 检测取样误差

### 1.3.2 排查步骤

1. 对降温记录：前体合格判定与降温的先后顺序
2. 查酵母排放记录：还原期排了几次排了多少
3. 看过滤时浊度与压力波动
4. 同一样品双份送检，排除检测波动
5. 追同批其他罐，分清个罐问题还是批次问题

### 1.3.3 对策

轻微的按工艺评估回罐升温还原后重新过滤；严重的按不合格品处理，**不许靠兑稀释过关**。

预防三件事：**前体合格再降温；还原期保留足量活性酵母；取样规范统一**。

## 1.4 DMS 偏高（玉米味）

### 1.4.1 为什么会出现

DMS 前体来自麦芽，在糖化温度段和煮沸早期生成。DMS 高三条路：

1. 煮沸强度不够或时间不足，前体没蒸掉
2. 排风冷凝回流设计/故障，蒸出去又凝回来
3. 麦芽本身前体高（新批次、储存不当）

### 1.4.2 排查步骤

1. 查这批麦汁的煮沸记录（蒸发量、时间、温度曲线）
2. 查排风冷凝器状态
3. 查麦芽批次变化
4. 对比同麦芽不同罐数据，分清麦汁侧还是发酵侧
5. 化验确认前体与游离 DMS 比例

### 1.4.3 对策

煮沸不足补强度补时间；设备报修；麦芽问题反馈采购和工艺。预防：每批麦汁记录蒸发量，新麦芽先小试。

## 1.5 本章小结

发酵异常的排查心法一句话：**酵母是活的，环境变了它就变**。温度、氧气、杂菌这三个环境变量查透了，大部分"疑难杂症"都有答案。

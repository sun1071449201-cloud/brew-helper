# 第三章 过滤与灌装：守住酒的最后尊严

糖化发酵决定了酒的上限，过滤灌装决定的是**下限**——酒在罐里再好，过滤灌装搞砸了，到消费者嘴里的就是另一回事。这一章把两道工序的 SOP 串起来讲。

## 3.1 过滤机启机：慢就是快

### 3.1.1 启机五步

1. **顶机排气**：脱氧水把机内空气顶干净——空气碰到酒，氧就进去了，保质期的账从这一刻开始记
2. **预涂**：按规程做预涂，滤层初始通道全靠它。预涂不好，运行中怎么补都吃力
3. **缓慢起压**：压力猛了滤层被打穿，浊度立刻上脸
4. **首样确认**：出口头一段酒取样看浊度，合格再切清酒罐
5. **参数记录**：预涂量、顶水用量、起压时间，班班记

### 3.1.2 运行中盯三样

- **进出口压差**：压差爬升快是滤层堵了，到上限立即换洗——硬顶必穿，穿了你面对的是浊度和微生物两头着火
- **浊度仪**：超标自动回流；回流持续降不下来就停机，别把坏酒往后送
- **流量平稳**：忽大忽小先查泵和阀门，再查滤层

### 3.1.3 现场检查清单

- [ ] 脱氧水顶机排气完成
- [ ] 预涂量与规程一致
- [ ] 首样浊度合格
- [ ] 压差/浊度/流量已记录
- [ ] 换洗按压差上限执行（未硬顶）

## 3.2 浊度控制：先分清是哪种浑

### 3.2.1 三种浑三副药

- **开机就高** → 预涂问题，重做预涂
- **中途涨** → 滤层穿透或进料酒脏，反馈发酵工序
- **尾部涨** → 滤层到寿命，换洗

低温起雾、回暖复清是冷浑浊，属可逆析出——先分清类型再动手，方向错了怎么调都白调。

### 3.2.2 应急纪律

回流阀常开备用；回流超过时限还降不下来，**停机**。灌装线不等人，但坏酒送过去就是批量事故——停机的损失永远小于流下去的损失。

## 3.3 灌装机启机：启机质量决定一个班次

### 3.3.1 启机清单

1. CIP/SIP 状态确认——清洗记录没闭环不许开线
2. 酒温与背压确认——温度高了起泡，背压低了跑 CO2
3. 空瓶瓶盖供应确认，不合格盖子先挑出来
4. 空机试运转，听声音看动作，再上酒

### 3.3.2 首件确认

开线后前几瓶全检：液位、盖子扭矩、外观。首件不合格**停线调整**，别让坏酒流下去——首件省的两分钟，可能是后面两小时的返工。

### 3.3.3 运行盯守

- 定时抽检液位和密封性
- 看酒头挂泡、听灌装阀异响
- 换罐衔接按规程，防止混罐——**混罐是灌装车间最贵的事故之一**

## 3.4 背压与酒温：CO2 的账

### 3.4.1 道理先讲透

CO2 在酒里溶多少，看温度和压力。酒温一高，CO2 往外跑：起泡、冒酒、液位不稳全来了。所以**先把酒温稳住，再谈背压**。

### 3.4.2 操作三要点

1. 换罐或停线再开，先核对酒温和罐压——别凭感觉
2. 背压气用 CO2，**用压缩空气等于主动充氧**，保质期直接受损
3. 酒缸压力波动超范围，先查稳压装置再调灌装

### 3.4.3 冒酒处理

冒酒多了先降速再查因。一味提速，是拿损耗和微生物风险换产量——这笔账怎么算都是亏的。

### 3.4.4 现场检查清单

- [ ] 酒温在工艺卡区间内
- [ ] 背压气源为 CO2 且压力稳定
- [ ] 首件全检合格
- [ ] 换罐核对（温度/压力/罐号）已执行
- [ ] 损耗率按班记录，趋势异常已上报

## 3.5 本章小结

过滤和灌装的共同心法：**下游是替上游把关的最后一道闸**。过滤替发酵把关浊度和氧，灌装替过滤把关损耗和卫生。闸门失守，前面所有努力一起报废。

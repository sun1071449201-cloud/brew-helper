# 第一章 糖化与发酵：把糖变成酒

整个酿造，说白了就是一件事：**把麦芽里的淀粉变成糖，再把糖变成酒**。前半场是糖化，后半场是发酵。这两道工序的质量上限，就是这罐酒的质量上限——后面过滤灌装再精细，也只能守住下限。

## 1.1 糖化：酶的世界

### 1.1.1 糖化的本质

糖化就是**喂酶干活**。麦芽里有两类关键酶：一类把长链淀粉剪成可发酵糖（产糖），一类把蛋白质剪成酵母的口粮（产氮）。两类酶干活的最佳温度不一样，所以才有"分段控温"这个说法。

理解了这一点，很多操作就通了：

- 温度分段不是玄学，是**按酶的脾气排班**
- 保温时间不是越久越好，酶干完活就该进下一道
- pH、水粮比、温度三件事互相牵扯，动一个要想到另外两个

### 1.1.2 投料的坑

投料最常见的坑就三个：**结团、温差、记录缺失**。

1. **结团**：下料太快或搅拌跟不上，粉结成干团。团里是干的，酶进不去，后面碘检怎么都不合格。下料匀速、搅拌到位，是糖化工最基本的基本功。
2. **温差**：冬天麦芽是凉的，投料水温照夏天经验走，醅温直接偏差。**先测粮温再算水温**，App 里的"热水用量"工具就是干这个的。
3. **记录缺失**：实际投料水温、醅温、时间不记，出问题就是一团乱麻。记录是给未来的自己看的。

### 1.1.3 碘检怎么做才不骗人

碘检是判断淀粉残留的现场手段。三个细节决定它准不准：

- **取样要冷却到室温**再滴碘，热醅直接滴颜色反应不可靠
- **取样口先放掉存样**，否则测的是管子里的旧醅
- 碘液要在有效期内，变色判断对着标准卡比

碘检不合格先延长保温再检一次；还不行，报工艺员，**别自己加酶**——加酶是工艺变更，不是操作处置。

### 1.1.4 现场检查清单

- [ ] 现场温度计与 DCS 显示一致（差 2°C 以上报仪表）
- [ ] 醅面无干粉团、无浮料
- [ ] 上中下三点温差在标准内
- [ ] 每个阶段起止时间与温度已记录
- [ ] 碘检结果（含取样冷却）已记录

## 1.2 发酵：伺候好酵母

### 1.2.1 酵母是什么地位

酵母不是原料，是**牲口**——得喂好、不能累着、不能冻着。发酵的全部管理，归根结底就是让酵母在合适的环境里干活：温度合适、氧气前期够、营养够、别让它接触杂菌。

### 1.2.2 酵母扩培不是倒进去就完

酵母扩培不是倒进去就完。先看活率——活率低了就别接了，接了也是白扩。扩培温度比你主发酵温度略高一点，让酵母先"热身"。扩培到降糖速度开始放缓时，就可以准备接种了。

接种前四件事，一件都不能省：

1. **查活率**：实验室报告低于线就停
2. **查染菌**：镜检有杂菌整罐弃用
3. **查麦汁**：充氧、温度到位没有
4. **查管路**：酵母管路洗了吗

### 1.2.3 主发酵巡检：四件事

每天巡检每个罐过四件事：**看温度、看压力、看降糖、听声音**。

- 温度压不住先查冷媒再查仪表，别猛拉控温点
- 降糖每天固定时间取样，画曲线看趋势
- 压力大起大落伤酵母也伤罐
- 起泡声音变弱，配合降糖数据判断发酵是否放缓

### 1.2.4 双乙酰还原：为什么不能早降温

双乙酰是那个馊饭味。酵母把前体转化为双乙酰，再还原掉。还原靠的是酵母活性——**酵母睡了，还原就停了**。

所以纪律就一条：**前体检测合格之前，不许降温**。还原期间每天送检，合格才能分阶段降温。降温降早了，双乙酰反弹是过滤灌装阶段最烦人的事故，而那时候能做的只有返工。

### 1.2.5 现场检查清单

- [ ] 接种记录完整（活率、接种量、时间、罐号）
- [ ] 巡检四件事已做且记录当场写
- [ ] 还原期温度未被提前下调
- [ ] VDK 送检记录与前体合格判定在案
- [ ] 降温按阶段执行，速率符合工艺卡

## 1.3 交接班：最容易翻车的五分钟

### 1.3.1 交接什么

- 各罐当前温度、糖度、压力、所在阶段
- 当班做过什么操作、有什么异常、报了什么修
- 待办事项：几点要取样、哪个罐要降温、哪个罐要排酵母

### 1.3.2 怎么交接

口头说一遍，记录签一遍，关键罐去现场看一眼。三样都做了才算交完。**"应该没问题"是交接里最危险的四个字**。

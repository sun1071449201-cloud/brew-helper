# 导读：怎么用这本手册

这本手册是写给刚进酿造车间的一线操作员的，不是写给坐在办公室里看报表的人的。它的每一章都按"先讲为什么 → 再讲怎么避坑 → 最后讲现场怎么检查"的顺序来写，因为**不理解为什么的操作，一遇到异常就会慌**。

## 这本手册的三个使用场景

### 场景一：上岗前通读

第一章、第二章按顺序读完，把工序的逻辑串起来。不求背下来，只求遇到事知道去哪查。

### 场景二：操作前对照

上岗接任务，先把对应小节扫一遍，看看"现场怎么检查"那一段，照着清单走一遍不丢人，出事故才丢人。

### 场景三：异常时翻查

配合 App 的"异常排查"Tab 用：先按症状搜，找到根因方向，再回到这里补背景知识。

## 关于数据的三条铁律

1. 本手册里所有温度、时间、浓度、压力**都是经验参考值**，全部标注"以本厂 SOP 为准"——不是我们不敢给数，是因为**每个厂的设备、水源、菌种、麦芽都不一样**，照抄别厂的数等于拿自己的产量赌博。
2. 凡是与本厂工艺卡冲突的地方，**工艺卡永远是对的**。手册只负责告诉你为什么工艺卡这么定。
3. 遇到手册没写的异常，先停手、报告、查记录，别凭感觉动设备。**酿造的大部分事故，都是"我觉得没问题"造成的。**

## 配套 App 工具

- **SOP 查询**：按工序分类查操作要点，支持全文搜索
- **工艺计算器**：比重换算、IBU、补糖、CO2 对照等 8 个现场计算器
- **异常排查**：按症状搜故障，症状 → 原因 → 排查 → 对策
- **酿造术语**：中英双语术语库，看不懂的词随手查

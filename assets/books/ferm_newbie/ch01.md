# 第一章 认识车间：从一粒麦到一瓶酒

## 1.1 全流程地图

先把整条线走一遍，你才能知道自己站在这条线的哪个位置：

```
麦芽粉碎 → 糖化（酶把淀粉变糖）
        → 过滤槽（麦汁和麦糟分离）
        → 煮沸锅（灭菌 + 加酒花 + 蒸掉怪味）
        → 回旋沉淀（分离热凝固物）
        → 冷却充氧 → 接种酵母
        → 主发酵（糖变酒 + CO2，控温）
        → 双乙酰还原 → 降温储酒
        → 过滤（清亮）→ 清酒罐
        → 灌装（背压防起泡）→ 杀菌（PU）→ 喷码 → 出厂
```

**记住两句话**：糖化发酵造酒的品质上限，过滤灌装守品质下限，包装出厂守安全底线。

## 1.2 你会打交道的设备

### 1.2.1 罐子家族

- **糖化锅/过滤槽**：糖化工序的主战场
- **煮沸锅**：全车间温度最高的地方，蒸汽和烫伤都和它有关
- **发酵罐（锥形罐）**：酵母干活的厂房，锥底排酵母、罐顶起泡，温度压力是它的脉搏
- **清酒罐**：过滤后的酒等待灌装的中转站

### 1.2.2 管路与阀门

车间里管子满天飞，先认三类：**酒管路**（卫生级，碰前想 CIP）、**冷媒管路**（结霜的）、**蒸汽管路**（烫的）。阀门认不清就不碰——**新人在第一周碰错一个阀门，可能是全厂的事故**。

### 1.2.3 仪表

- 温度：现场玻璃计 + DCS（中央控制）——两边要对得上
- 压力：罐顶压力表
- 流量、液位：按岗接触

**仪表是工艺的眼睛**，后来你会发现"异常排查"一半的功夫花在确认仪表本身没坏上。

## 1.3 工艺卡：车间的宪法

每道工序都有工艺卡：温度、时间、压力、浓度的目标值和允许范围全在上面。**新人的第一课是把本岗位工艺卡看熟**——App 里的参数速查是经验参考，工艺卡才是你当班的依据，两者冲突时工艺卡说了算。

## 1.4 第一周安全地图

跟着这条清单走一圈（由师傅带）：

- [ ] CO2 报警仪位置 + 报警声音
- [ ] 冲淋洗眼装置位置
- [ ] 你所在岗位的 MSDS 位置
- [ ] 疏散路线 + 集合点
- [ ] 急救箱、AED 位置
- [ ] 本岗位的急停按钮

**这六样东西的位置，第一周就要摸熟。** 安全红线三条（CO2/碱液/进罐）先去"安全红线"页背熟——具体去读《酿造安全红线手册》第一章。

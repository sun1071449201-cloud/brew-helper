# 第三章 机械、热与玻璃：看得见的危险

相比 CO2 和氨的"无形"，这一章的危险都看得见——**但看得见的危险，伤人一点也不慢**。

## 3.1 热烫伤

### 3.1.1 危险源地图

- 糖化锅、煮沸锅：七八十度以上的醅和麦汁
- CIP 碱罐：高温碱液，烫伤 + 化学烧伤双重伤害
- 蒸汽管路、排汽口：看不见的高温气体
- 热水管路：保温层破了的地方裸奔

### 3.1.2 红线条目

- 锅沿取样**站侧面**，脸别探到锅口正上方——蒸汽和溅液都往正上方走
- 搅拌、升温操作前确认锅盖/挡板到位
- 高温管路的保温层**别当扶手**——缺保温层的位置烫一下就是一片
- 泄压排汽口方向要清楚，站位避开

### 3.1.3 应急

流动冷水冲 15 分钟以上 → 别涂牙膏别挑水泡 → 就医 → 报告。衣服粘住皮肤别硬撕。

## 3.2 机械伤害：旋转与夹点

### 3.2.1 危险源

- 输送机、灌装机链条、风机叶片：**旋转部件**
- 罐口、泵体、阀门之间：**夹点**（两个运动或静止部件之间能夹住身体的空间）

### 3.2.2 红线条目

- **运转中不清理、不调整、不润滑**——这三件事是机械伤害第一名
- 转动设备检修：停机、断电、挂牌（上锁挂牌 LOTO）——**"我马上就好"是断指事故的口头禅**
- 长发、围巾、松垮袖口远离旋转设备
- 防护罩拆了必须装回去，缺罩设备报修停用

### 3.2.3 上锁挂牌（LOTO）是什么

检修电气/机械设备时：断电源 → 上锁 → 挂牌（写明检修人和原因）→ 验证无电/无压 → 作业。**牌子和锁是生命的门闩——谁上锁谁开锁，别人无权代开。**

## 3.3 玻璃瓶与爆瓶

### 3.3.1 危险源

- 补糖过量 → 瓶内压力超限
- 杀菌超温/卡瓶超时 → 局部过压
- 瓶子暗伤（划痕、磕碰）→ 承压下降

### 3.3.2 红线条目

- 补糖严格按工艺卡复核，**二次补糖双人确认**
- 杀菌机超温报警**立即停链**处理；卡瓶超时批次单独评估
- 碎玻璃：**防割手套 + 夹子**，不用手；破瓶当场隔离
- 听到杀菌机异响先停机再查

### 3.3.3 爆瓶的物理账

瓶内压力来自 CO2：温度每高 10°C，同等溶解量下压力显著上升。**爆瓶不是"运气差"，是压力账算错了或者工艺纪律松了**——用 App 的 CO2 工具把账算清楚，比事后捡碎玻璃便宜一万倍。

## 3.4 滑倒与坠落：最被低估的伤害

### 3.4.1 危险源

- 湿滑地面（清洗水、漏酒）、楼梯、罐顶平台
- 临时线缆横过通道

### 3.4.2 三条习惯

1. 见水渍酒渍**顺手拖掉**（这是全车间受益的习惯）
2. 高处作业（罐顶、平台）走规定通道，**工具用袋吊**不抛接
3. 楼梯扶手是给你扶的，不是摆设

## 3.5 本章小结

看得见的危险有个特点：**所有人都知道危险在哪，事故却照样发生**——因为熟悉会磨掉敬畏。这一章每一条红线，都是"知道但没当回事"的事故换来的。

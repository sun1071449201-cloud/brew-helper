# 第一章 CO2 与密闭空间：酿造厂最凶险的两件事

## 1.1 CO2 窒息

### 1.1.1 为什么它这么危险

三个原因叠加：

1. **它无处不在**：发酵产 CO2，是酿造的必然副产品，每罐酒都在产
2. **它没有预兆**：CO2 无色无味，高浓度下人几口呼吸就失去意识——没有呛咳、没有警报感，站着就倒
3. **它会藏**：CO2 比空气重，沉在罐底、地沟、地坑、酒窖低洼处，通风死角常年积聚

### 1.1.2 红线条目（背诵级）

- 进发酵间、清酒间先看**固定式报警仪读数**，便携仪随身带
- **绝不单独进入**有 CO2 报警的区域作业
- 掉落在地坑、罐区的物品：**先通风、再检测、后捡拾**
- 罐体排压必须接排空管路到室外，**不许往车间里排**

### 1.1.3 有人倒下了怎么办

**第一反应是呼救和通风，不是冲进去。** 盲目施救制造第二个伤员，是窒息事故的标准剧本。正确顺序：呼救 → 启动应急 → 确认自身防护（ portable 仪、通风）→ 按预案施救。

### 1.1.4 现场检查清单

- [ ] 报警仪读数正常（且在检定有效期内）
- [ ] 便携仪随身
- [ ] 作业区通风系统运行正常
- [ ] 独自作业的区域已报备（或已两人同行）

## 1.2 密闭空间作业

### 1.2.1 什么是密闭空间

发酵罐、清酒罐、水箱、地沟——**任何进去容易、出来难、空气不流通的空间**。里面的危险三件套：缺氧、CO2 残留、清洗剂残留（碱/酸蒸气）。

### 1.2.2 红线条目（背诵级）

- **无作业票不进罐**——这是铁律，没有任何例外
- 进罐前：通风置换 + 检测氧含量和有害气体，**数据合格才进**
- 罐外**监护人全程在岗**，通讯畅通，救援器材放罐口
- 罐内照明用安全电压；动火另办动火票

### 1.2.3 为什么"就进去看一眼"也不行

"就看一下"的三个致命假设：假设罐里空气正常（上一个工序可能刚排过 CO2）、假设有人会发现你（没人知道你进去了）、假设你扛得住（缺氧 20 秒判断力就崩）。**每一个进罐事故的起点，都是"就进去看一眼"。**

### 1.2.4 作业票流程走一遍

1. 申请作业票：写明罐号、作业内容、时间
2. 隔离：工艺管线断开或上盲板，**光关阀不算隔离**（内漏会串）
3. 清洗置换、通风
4. 检测：氧含量 19.5%~23.5%、有害气体合格
5. 监护人到位、救援器材到位
6. 进罐作业，期间定时复测
7. 撤出销票

### 1.2.5 罐里的人出事了

监护人第一反应：**呼救、启动应急预案**——不是自己进罐。没有防护进罐救人是第二起事故。用三脚架/安全带把人吊出、外部通风、按预案施救。

## 1.3 本章小结

CO2 和密闭空间的共同点：**都杀人于无形，都败于"我觉得没事"**。把检测、通风、监护三个动作变成肌肉记忆，这两个杀手就没有机会。
